# GigaChat-AI-Cube-Game

Интерактивная 2D-игра на движке Unity, где главным героем является куб, управляемый искусственным интеллектом через API GigaChat.

## Как играть
Игрок общается с ИИ-персонажем через текстовое поле ввода. На основе ответов нейросети игра динамически спавнит объекты (мосты, батуты) и меняет свойства физики в реальном времени.
